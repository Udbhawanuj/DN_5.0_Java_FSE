# React Hands-on 1–19

Each folder is an independent React application with its own `package.json`.

From the Week 6 root folder:

```bash
npm install
npm run hol -- 1
npm run hol -- 19
```

From an individual application folder:

```bash
npm install
npm start
```

The mandatory React hands-on from the supplied mandatory mapping are covered, and the additional React hands-on are included as well.
