# Git Hands-on 1–5

The five command guides correspond to the supplied Cognizant Git hands-on documents:

1. Configuration and first commit
2. `.gitignore`
3. Branching and merging
4. Merge-conflict resolution
5. Cleanup, pull and push

Run commands in Git Bash and replace placeholder remote URLs with your own GitHub repository URL. Use personal credentials only; do not use Cognizant credentials.
