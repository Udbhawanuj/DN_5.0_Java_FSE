# Submission Checklist

1. Extract the ZIP.
2. Open the extracted root folder in VS Code.
3. Run `npm install` once from the root.
4. Run `npm start` to start HOL 1, or `npm run hol -- 6` to start another HOL.
5. Run `npm run verify` to build every app and execute the automated tests.
6. Commit the complete `Week6_Complete_Submission_Udbhaw_Anuj` folder to the Week 6 directory in your GitHub repository.
7. Do not commit `node_modules` or `dist`; they are already ignored.
