# DevOps Fundamentals
DevOps combines development, operations, quality and security practices to deliver software frequently and reliably.


## Main Goals
1. Shorten the software delivery cycle.
2. Automate repetitive build, test and deployment work.
3. Improve collaboration and shared ownership.
4. Detect failures early using continuous feedback.
5. Make releases repeatable, observable and reversible.


## Core Practices
- Version control for application and infrastructure code
- Continuous integration
- Automated testing
- Continuous delivery/deployment
- Infrastructure as Code
- Containerization
- Monitoring, logs and alerting
- DevSecOps and secret management
- Blameless incident reviews


## CI, Continuous Delivery and Continuous Deployment
- **Continuous Integration:** developers merge small changes frequently; every change is built and tested.
- **Continuous Delivery:** every successful build is release-ready, but production deployment requires approval.
- **Continuous Deployment:** every successful change is automatically deployed to production.


## Useful Metrics
- Deployment frequency
- Lead time for changes
- Change failure rate
- Mean time to recovery
