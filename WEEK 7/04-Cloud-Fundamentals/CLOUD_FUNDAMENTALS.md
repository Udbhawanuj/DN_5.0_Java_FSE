# Cloud Computing Fundamentals

## Service Models

- **IaaS:** virtual machines, networking and storage; customer manages OS and application.
- **PaaS:** managed runtime and platform; customer focuses on application code.
- **SaaS:** complete software delivered to end users.
- **FaaS/Serverless:** event-driven functions billed by execution.

## Deployment Models

- Public cloud
- Private cloud
- Hybrid cloud
- Multi-cloud

## Benefits

- on-demand resources
- elasticity
- global reach
- managed services
- pay-as-you-use pricing
- automation through APIs and Infrastructure as Code

## Shared Responsibility

The cloud provider secures the cloud infrastructure. Customers remain responsible for identities, permissions, data classification, application security and configuration appropriate to the selected service.
