# Container Orchestration

Container orchestration automates scheduling, scaling, networking, health recovery and rolling updates for many containers.

## Why It Is Needed

- restart failed containers
- distribute replicas across servers
- expose stable service endpoints
- scale based on demand
- perform rolling updates and rollbacks
- manage configuration and secrets

## Common Platforms

- Kubernetes
- Amazon ECS
- Amazon EKS
- Docker Swarm
- Azure Kubernetes Service

The `kubernetes` folder contains a Deployment, Service and PersistentVolumeClaim example for the task service.
