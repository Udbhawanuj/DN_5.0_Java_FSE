# Offline GenAI Fundamentals Lab

This pure Java 17 application demonstrates GenAI engineering patterns without calling an external API.

- prompt templates
- bounded context construction
- prompt injection detection
- a mock language model client
- output validation
- a simple plan → retrieve → generate → validate → revise agent loop

Run `run.ps1` or `run.sh`. Run tests with `test.ps1` or `test.sh`.
