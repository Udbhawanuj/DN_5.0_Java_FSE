# Generative AI Fundamentals

Generative AI learns patterns from data and produces new text, code, images, audio or other content. Traditional discriminative models mainly classify or predict labels, while generative models produce new outputs.

## Important Terms

- token
- context window
- prompt
- model parameters
- temperature
- hallucination
- grounding
- retrieval-augmented generation
- embeddings
- evaluation

## Developer Responsibilities

- validate generated code and facts
- protect confidential data and credentials
- apply authorization outside the model
- test for prompt injection
- keep humans responsible for consequential decisions
- record model/version/configuration when reproducibility matters
