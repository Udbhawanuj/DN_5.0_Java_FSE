# GitHub Copilot Guide

## Setup

1. Install the GitHub Copilot extension in VS Code.
2. Sign in to the authorized GitHub account.
3. Open a trusted repository.
4. Review organization and privacy settings.

## Core Features

- inline code completions
- chat-based explanations and refactoring
- generation of tests and documentation
- codebase-aware questions where supported

## Safe Usage

- never accept code without reviewing it
- run tests, linters and security checks
- avoid sending secrets or proprietary data without permission
- verify licenses and organization policies
- treat generated code as an untrusted draft
