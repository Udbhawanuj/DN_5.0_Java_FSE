# AI Security and Ethical Considerations

## Risks

- hallucinated facts or APIs
- insecure generated code
- prompt injection
- secret exposure
- biased output
- intellectual-property and licensing concerns
- excessive automation without oversight

## Controls

- least-privilege tool permissions
- input and output validation
- allowlists for sensitive operations
- human approval for consequential actions
- audit logs
- adversarial testing
- grounded answers and citations
- rate limits and cost controls
