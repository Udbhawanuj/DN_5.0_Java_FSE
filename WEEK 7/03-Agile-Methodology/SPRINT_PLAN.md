# Two-Week Sprint Plan

**Sprint goal:** Deliver a tested and containerized Java task service with a repeatable CI pipeline.

| Day | Planned work |
|---|---|
| 1 | Refine user stories and acceptance criteria |
| 2–3 | Implement repository and task model |
| 4 | Implement REST endpoints and error responses |
| 5 | Add tests and health endpoint |
| 6 | Create Dockerfile and image |
| 7 | Add Compose network, volume and reverse proxy |
| 8 | Add GitHub Actions and Jenkins pipeline |
| 9 | Add cloud architecture and orchestration artifacts |
| 10 | Review, retrospective and submission evidence |

## Definition of Done

- code compiles with Java 17
- automated tests pass
- no secrets are committed
- Docker image builds
- health endpoint works
- documentation and acceptance criteria are updated
